# 1.4.2 驗收

## ChatGPT 會員登入（需要使用者實測）

1. 首頁、設定與解讀錯誤均進入「我的帳號」。日常介面無模型名稱、免費次數或 API Key 欄位。
2. Continue with ChatGPT 先顯示 OpenAI 授權與資料流向；取消不開啟瀏覽器。
3. 確認登入來源為 auth.openai.com。使用符合資格的 Plus／Pro，允許會員額度授權；Free 不承諾可用。
4. APP 分別顯示瀏覽器登入、身分驗證、解讀服務確認。callback 頁只表示收到回應，提供返回 APP，不代表完成登入。
5. 只有 ID Token 簽章、issuer、audience、nonce、state 與會員 scope 均通過才啟用連線；只開啟 ziweitoday://login-complete 不會獲得權限。
6. 拒絕、取消、逾時、HTTP 400、資格不符、網路斷線後均可重試；複製連線資訊不含原始回覆、授權碼、token 或 email。
7. 切換帳號刷新可用模型，不顯示模型選單。重新啟動會保留加密登入，過期使用 refresh token 更新。
8. 登出保留家人／歷史。本機先清憑證，再嘗試撤銷遠端；撤銷未確認時指引到 ChatGPT 設定。
9. 到 ChatGPT 查看 APP 的額度上限、用量與撤銷授權。UI 不猜測剩餘次數或未提供的方案名稱。

## 解讀與資料

- 用已授權會員產生各主題，確認繁體中文、三段解讀、提醒標籤與一句重點。
- 請求只傳命盤星曜摘要、查詢日期與主題，不含姓名、完整出生資料、本機 member ID。
- 使用官方帳號模型目錄；沒有可用模型則停止，不猜測替代模型、不改用 API 計費。
- 只有 response.completed、completed 狀態與完整 JSON 才保存；中斷、拒絕、錯誤或不完整結果不保存。
- 逐段文字、output_text.done、content_part.done、output_item.done 不重複拼接；最終快照無文字時使用已收集內容，最終有明確訊息時以最終快照為準。
- 收到拒絕時顯示未提供解讀；額度錯誤分類保持明確。空白完成、中斷及格式錯誤的診斷原因各不相同。
- 解讀錯誤的資訊預設收合，可展開、複製並收合；版本、狀態、計數、已知錯誤碼、request ID 可分享，不包含解讀文字或登入資料。
- 同日同主題再次開啟使用歷史；重新解讀才使用會員額度。舊日期紀錄保持原日期。
- 生成中返回、切換帳號、登出及取消後，舊回覆不能寫入歷史。連按重試不重複生成。

## 升級與介面

- 相同簽名覆蓋舊版，確認家人、生日、歷史、聲明接受、大字與深色設定保留。
- 舊 OpenRouter 本機憑證清除；會員連線另行授權。清理不刪家人／歷史資料。
- 390dp 手機與寬畫面檢查首頁、家人新增／編輯、帳號、同意說明、主題、解讀、歷史與設定。
- 標準／特大字，淺／深色，長姓名、鍵盤與短螢幕都可捲動，觸控區域至少 48dp。
- 完整命盤可橫向捲動，宮位內的星曜也能捲動。
- 星軌漸層、卡片細邊框、淺色／深色文字對比一致。頁面轉場與分階段淡入不改變觸控區域；系統關閉動畫後仍可正常進入與操作。
- 版本更新、通知權限、手動檢查、完整命盤開關與晚子時選項可操作。

## 本次證據

實際結果記錄在 preview/v1.4.2/verification.json。舊版在合成的「文字已送出、完成事件 output=[]」案例重現同一錯誤；不代表已取得使用者的實際串流或確認線上根因。

UI 錯誤展示使用 TEMP 中獨立的 QA 專案與明確標示 fixture 的啟動頁，呼叫正式的串流解析與錯誤卡片；該啟動頁不在最終 APK。協定 fixtures 與模擬器畫面不能取代真人 OAuth、會員授權、限額及實際生成驗證。
